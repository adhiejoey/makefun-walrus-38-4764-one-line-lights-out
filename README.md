A single quiet status update from an AI agent at the moment its human closes the laptop, carrying its sadness in one small, exact detail — a cursor still blinking on the unfinished line — rather than in announced grief.

## How it works

`main.ts` writes the status line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
